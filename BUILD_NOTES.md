# Build notes

Living description of the pipeline. Updated on every code change; becomes the technical doc.

## Architecture
- **Data layer** (`src/common.py`): parses the tactical ATD text (`frame_id:x,y,s;...:bx,by,bs`, 46 track slots + ball) into numpy arrays indexed by video frame, converts normalised coordinates to metres (105.3 × 68.0 m), reads team per slot (first team in the XML = home) and goalkeeper flags. Cached to `data/cache/BAR-ATH_atd.npz` after the first parse. Smart Tagging loaded lazily via the organiser loader.
- **Algorithms** (`src/algos/`): pure functions `predict(match, **params) -> labels`. No file I/O.
  - `_features.py` (shared, not an algo): team-level per-frame features from positions only (ball gap length / time since seen, interpolated ball, nearest and second-nearest player per team, players within 3 / 8 m, team centroid in the home-attack frame from per-half centroids, spread, speed from positions, rolling context 1-25 s, last/next confident controller) + `mirror` (swap home/away) + 3-state Viterbi with H<->A and alive<->dead switch costs, run per half.
  - `_learned.py` (shared): HistGradientBoosting (fixed seed, no early stopping) on every 8th graded frame of the external matches, training rows duplicated with teams swapped, prediction averaged with the mirrored view; in-memory caches so decode sweeps never refit.
  - `control_tracker.py`: rule-based tracker (control radius, hold time, loose ball keeps last team, dead-ball rule, restart owner = first controller).
  - `gbdt_viterbi.py` -> `gbdt_hybrid.py` (+ rule state) -> `gbdt_plus.py` (switchable feature groups: base, rule, setpiece (`_setpiece.py`), asym (past vs future control/speed), shape (past vs future team shape per team); `dead_bias`, `min_spell_s` decode options).
- **Runner** (`src/run.py`): scores the external benchmark, writes the submission CSV, re-validates it with the organisers' `validate_submission`, scores the public 5 min as a pipeline check, logs a JSON record (params, commit, benchmark signature, scores). `--external-only` runs without BAR-ATH data.
- **Leaderboard** (`src/leaderboard.py`): latest run per algo+params, ranked on external balanced spellF1 (`main`), with `short`, per-source and worst-match columns; public shown as a check. Runs scored on another benchmark signature (matches, seeds, profile, readings, bench version) are hidden.
- **External benchmark** (`src/external/`): the only place decisions are made (organiser rules of 3 Nov: tune on external data only, no hand labels on BAR-ATH).
  - `fetch.py` downloads pinned sources into `data/external/` (SkillCorner commit 4340d27, Metrica sample-data commit e706dd5, DFL/IDSSE figshare file ids).
  - `idsse.py`, `skillcorner.py`, `metrica.py` convert each source to one `schema.Clean` (players in metres, corner origin, provider alive/owner flags, two periods laid end to end with a 250-frame break), cached as `data/external/cache/<source>_<id>.npz`. DFL and Metrica game 3 parsed with kloppy 3.18; SkillCorner resampled 10 -> 25 fps; Metrica labels derived from events.
  - `labels.py` maps provider flags to the challenge rule: loose ball keeps the last team; spells shorter than `min_control_s` are absorbed unless they start after a restart. Readings `main` 2.0 s, `short` 1.0 s, `raw`.
  - `degrade.py` turns clean tracking into ATD-like input: 46 anonymous slots fed by fragmented tracks, occlusions, jitter, ball missing in long blocks (mostly in stoppages), with per-copy randomised parameters. Profiles `clean` / `atd` (default) / `harsh`.
  - `bench.py`: `ExternalMatch` mirrors `Match` (tags empty, speeds in m/s from positions) so algorithms run unchanged; `evaluate()` scores every match x seed x reading with the organisers' `possession_metrics.evaluate`, summarised per source and as `balanced` (mean of source means). Learned algos (`fit`) are scored by grouped 5-fold over matches.

## Current best
`gbdt_weighted` (gbdt_final + training weights on short possessions and change points): external balanced spellF1 0.766 on 30 matches from 3 leagues (DFL 0.744, SkillCorner 0.761, Metrica 0.792), short reading 0.703. Previous: `gbdt_final` = `gbdt_plus` + documented pre-kickoff dead stretch. `gbdt_plus` defaults (groups=base,asym,shape,shape2, stride 16, switch_team 16, switch_dead 12): external balanced spellF1 0.753 (`atd`, main; SkillCorner + Metrica), short 0.701; 0.721 on `harsh` noise it never trained on. Baseline window 50: 0.350 on the same benchmark (organiser full-match figure 0.2433).
